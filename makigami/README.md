# 巻紙（まきがみ）

縦書き・巻物風の小説エディタ。GitHub Pages に置いてホーム画面に追加して使う。

## ファイル
- `index.html` … アプリ本体
- `sw.js` … オフライン用（中身を更新したら先頭の `V` の番号を上げる）
- `manifest.webmanifest`、`icon.svg`、`icon-192.png`、`icon-512.png` … ホーム画面用

## 置き方
1. GitHub のリポジトリに `makigami` フォルダごと入れる（例：`Amethyst-liyon/server/makigami/`）
2. 開くURLは `https://amethyst-liyon.github.io/server/makigami/` のようになる
3. スマホは Chrome で開いて「ホーム画面に追加」

## Googleドライブ同期の準備（最初に一度だけ）
1. https://console.cloud.google.com/ で新しいプロジェクトを作る（名前は「巻紙」など）
2. 「APIとサービス」→「ライブラリ」→ **Google Drive API** を有効にする
3. 「OAuth 同意画面」を作る
   - ユーザーの種類：**外部**
   - アプリ名・メールは自分のもの
   - スコープは追加しなくてよい
   - テストユーザーに **自分の Gmail** を追加（公開ステータスは「テスト」のままでOK）
4. 「認証情報」→「認証情報を作成」→「OAuth クライアント ID」
   - 種類：**ウェブアプリケーション**
   - 承認済みの JavaScript 生成元：`https://amethyst-liyon.github.io`
   - リダイレクトURIは空でよい
5. できた「クライアントID」（`…apps.googleusercontent.com`）をコピー
6. アプリの「引き出し」→「同期」に貼り付けて「ドライブにつなぐ」
   - 「このアプリは確認されていません」と出たら「詳細」→「（安全ではないページ）に移動」で進む（自分で作ったアプリなので大丈夫）
7. スマホでも同じクライアントIDを入れる

## ドライブの中身
```
執筆/
  巻紙について.md        … Claude 向けの説明
  作品名/
    01_第一章.md          … 章ごとの本文（番号が順番）
    02_第二章.md
    設定.md               … 設定メモ
    下書き_Claude_日時.md … Claude が置く下書き（何個でも）
```
アプリが書き換えるのは自分で作ったファイルだけ（drive.file 権限）。Claude の下書きを拾うために、ドライブの読み取り権限（drive.readonly）ももらう。

## 同期のしくみ
- 書いている間は端末に自動保存。ドライブとはログイン後15秒ごと・アプリを閉じたときにそろえる
- ログインは1時間ごとに切れるので、そのときは下の「タップで同期」を押す
- 同じ章を2台で別々に直したときは、ドライブ版を「（ドライブ版）」としてすぐ後ろの章に残す（どちらも消えない）
- Ctrl+S（PC）でその場で同期

## 書き方
- ルビ：`｜漢字《かんじ》`（漢字だけなら `漢字《かんじ》` でも可）
- 傍点：`《《強調》》`
