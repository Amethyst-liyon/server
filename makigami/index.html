設定メモ

登場する種族、地名、出来事の順番など。ドライブには「設定.md」として保存され、Claude も読めます。

Claudeの下書き

Claude に「巻紙の〈作品名〉に下書きを書いて」と頼むと、作品のフォルダに 下書き_Claude_日時.md が置かれます。同期するとここに届きます。本文には自動で入らないので、使うものだけ取り込んでください。いらなくなった下書きはドライブから消せます。

Claudeが読めるもの

ドライブの「執筆」フォルダにある章ファイル（1章1ファイル）と設定.md。アイデア出しを頼むときは作品名を伝えると読みに行けます。

クライアントID

  1. Google Cloud でプロジェクトを作り、Google Drive API を有効にする
  2. OAuth 同意画面を「外部・テスト中」で作り、自分をテストユーザーに追加
  3. OAuth クライアントID（ウェブ）を作り、承認済みの JavaScript 生成元に を入れる
  4. できたクライアントIDを上に貼り付けて「ドライブにつなぐ」

原稿は「執筆／作品名」フォルダに章ごとのファイルで入ります。このアプリが作ったファイルしか触りません。PC とスマホで同じクライアントIDを入れてください。
